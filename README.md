# 🚦 City AI Engine (Urban Planning AI)

An AI-powered smart city prototype that predicts traffic conditions and analyzes citizen reports using Machine Learning and Generative AI.

Built for **Solution Challenge 2026 - Build with AI**

---

## 🌍 Problem Statement

Urban cities face challenges like:
- Traffic congestion
- Pollution hotspots
- Lack of real-time insights

This project acts as a **City Brain**, analyzing data and predicting traffic conditions to help smarter decision-making.

---

## 💡 Solution

City AI Engine combines:
- Machine Learning (traffic prediction)
- Generative AI (citizen report analysis)

It provides:
- Traffic predictions based on conditions
- AI-based understanding of real-world reports

---

## ⚙️ Features

✅ Traffic Prediction (ML Model)  
✅ AI-based Report Analysis (LLM)  
✅ Simple & Interactive Dashboard  
✅ FastAPI Backend  
✅ Clean UI (HTML, CSS, JS)  

---

## 🧠 How It Works

### 1. Traffic Prediction
Input:
- Traffic count
- Rain condition  

Output:
- Heavy Traffic / Low Traffic  

---

### 2. AI Report Analysis
Input:
- Citizen report (text)

Output:
- Traffic Level
- Location
- Reason

---
